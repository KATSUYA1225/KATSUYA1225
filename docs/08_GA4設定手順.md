# Google Analytics 4（GA4）設定手順

所要時間：約10分

---

## なぜ必要か

先行登録LPの訪問者数・登録率（CVR）を計測するため。
「何人来て、何人登録したか」がわかると、X投稿の改善ができる。

---

## Step 1. GA4プロパティ作成

https://analytics.google.com

1. 「測定を開始」→ アカウント名「AI企業OS」
2. プロパティ名「AI企業OS」
3. ビジネス情報を入力
4. 「ウェブ」を選択
5. サイトURL: `https://ai-kigyo-os.onrender.com`
6. ストリーム名: 「AI企業OS LP」

---

## Step 2. 測定IDを取得

設定完了後に表示される：
```
G-XXXXXXXXXX
```
このIDをコピーする。

---

## Step 3. Claude Code に測定IDを渡す

「GA4の測定ID取得した。`G-XXXXXXXXXX`」と教えてもらえれば、
`register.html` と `landing2.html` に即座に設定します。

（コメントアウト済みのコードがあるので、IDを入れるだけ）

---

## Step 4. 確認

GA4の「リアルタイム」レポートで、自分でLPにアクセスして計測されることを確認。

---

## 計測できるようになること

| 指標 | 内容 |
|------|------|
| セッション数 | LPの訪問者数 |
| 直帰率 | すぐ離脱した割合 |
| 平均滞在時間 | ページをどれだけ読んだか |
| コンバージョン | フォーム送信数 |
| 流入元 | X投稿からの流入か直接かなど |
