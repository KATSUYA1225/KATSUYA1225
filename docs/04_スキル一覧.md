## スキルのデータ構造

各スキルは `knowledge/{スキルID}/` フォルダに格納：

```
knowledge/sales/
├── skill.yaml     ← スキル定義（名前・料金・システムプロンプト）
└── playbook.md    ← 実行手順・ノウハウ（自動進化で更新される）
```
