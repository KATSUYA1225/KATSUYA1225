## 投稿のコツ

1. **最初の2行が命** → スクロールを止める一文を書く
2. **数字を使う** → 「38秒」「¥29,800」「30社」は具体性がある
3. **改行を多く** → 詰まったテキストは読まれない
4. **週5本を3週間** → 最低15本投稿すると反応が見えてくる
5. **返信・引用RTを活用** → エンゲージメントが高まる

## 残り枠の管理

実際の登録数に合わせて数字を手動で更新するか、
Formspree の管理画面で登録数を確認する。
