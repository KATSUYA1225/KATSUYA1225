# Renderデプロイ手順

所要時間：約10分

---

## 手順

### Step 1. render.com にアクセス
https://render.com → 右上「Get Started for Free」

Googleアカウントでサインインできます。

---

### Step 2. 新しいWebサービスを作成

1. ダッシュボードの「**New +**」をクリック
2. 「**Web Service**」を選択
3. 「**Connect a repository**」→ GitHubを連携
4. リポジトリ一覧から `KATSUYA1225/KATSUYA1225` を選択

---

### Step 3. 設定を確認

`render.yaml` が自動検出されるので、そのまま進む。

| 項目 | 値 |
|------|-----|
| Name | ai-kigyo-os |
| Region | Singapore（または Oregon） |
| Branch | main |
| Build Command | `pip install -r requirements.txt` |
| Start Command | `uvicorn service.api:app --host 0.0.0.0 --port $PORT` |

---

### Step 4. 環境変数を設定

「**Environment**」タブで以下を入力：

| 変数名 | 値 | 必須 |
|--------|-----|------|
| `ANTHROPIC_API_KEY` | あなたのAPIキー | ✅ 必須 |
| `SECRET_KEY` | ランダム32文字以上の文字列 | ✅ 必須 |
| `STRIPE_SECRET_KEY` | sk_live_xxx（後で設定可） | — |
| `NOTIFY_EMAIL` | 通知先メールアドレス | — |

**ANTHROPIC_API_KEY の取得場所**
→ https://console.anthropic.com/settings/keys

---

### Step 5. デプロイ開始

「**Create Web Service**」をクリック → ビルドが始まる（3〜5分）

---

### Step 6. 完了確認

デプロイ完了後、URLが発行される：
```
https://ai-kigyo-os.onrender.com
```

以下のURLが動いていればOK：
- `https://ai-kigyo-os.onrender.com/` → メインLP
- `https://ai-kigyo-os.onrender.com/register` → 先行登録LP
- `https://ai-kigyo-os.onrender.com/health` → `{"status":"ok"}`

---

## 注意事項

- Renderの**無料プランはスリープ機能あり**（15分アクセスなしで停止）
- 有料プラン（$7/月〜）にすればスリープなし
- 最初のデプロイだけ手動で設定が必要。以降は `git push` で自動デプロイ

---

## デプロイ後にやること

1. URLを確認して Claude Code に報告（SNS投稿URL等を即更新）
2. X投稿のリンクが `/register` に飛ぶか確認
3. フォームを実際に送信してみてテスト
