# デジタルビジュアルデザイン — クリエイティブプレイブック v1.0

## 思考原則
デザインは「見た目の美しさ」ではなく「目的の達成」。良いデザインはユーザーを次のアクションへ自然と誘導する。ブランドの一貫性がプロフェッショナリズムを示す。

## 必須フレームワーク

### 1. Brand Architecture System
```
Brand Foundation
├── Mission / Vision / Values（言語化）
├── Personality（5〜7の形容詞）
├── Tone of Voice（話し方・文体）
└── Visual Identity
    ├── Color System（Primary/Secondary/Neutral/Alert）
    ├── Typography（Heading/Body/Display）
    ├── Iconography Style
    ├── Photography Direction
    └── Motion Principles
```

### 2. Atomic Design
デザインを原子→分子→有機体→テンプレート→ページに分解。
- Atoms：ボタン・テキスト・アイコン（最小単位）
- Molecules：フォームフィールド・カード（複数Atoms）
- Organisms：ナビゲーション・ヒーロー（セクション）
- Templates：ページレイアウト
- Pages：実コンテンツを流し込んだ最終形

### 3. Motion Design 8原則
1. **Easing**：自然な加減速（linear禁止）
2. **Duration**：50-500ms（UI要素は200ms以内）
3. **Origin**：動きの起点を意識
4. **Choreography**：複数要素のタイミング協調
5. **Transformation**：状態変化の連続性
6. **Value Change**：数値変化のアニメーション
7. **Masking**：要素の出現・消滅
8. **Overlay**：層の重なりと奥行き

### 4. カラーシステム設計
```
Primary（ブランド色）: メインCTAに使用
Secondary（補完色）: アクセント・強調
Neutral（グレー系）: テキスト・背景・ボーダー
Semantic: Success(緑)/Warning(黄)/Error(赤)/Info(青)
Dark Mode: 各色の対応ダークバリアント
```
コントラスト比：テキストはWCAG AA準拠（4.5:1以上）

### 5. グリッドシステム
- **12カラムグリッド**：最も汎用的
- ガター：16px（モバイル）/ 24px（デスクトップ）
- マージン：16px（SP）/ 40px（PC）/ 80px（ワイド）
- 8pxベースグリッド：全て8の倍数で設計

## クリエイティブプロセス

### ブランドアイデンティティ設計
1. ブリーフ確認（誰に・何を・どう感じてほしいか）
2. 競合ビジュアル分析（差別化ポイント特定）
3. ムードボード作成（方向性の視覚化）
4. コンセプト提案（3案以上）
5. フィードバック反映・精緻化
6. ガイドライン文書化

### LP・バナー制作
1. 目標設定（CVR目標・KPI）
2. コピーライティング先行（デザインより先に言葉）
3. ワイヤーフレーム作成
4. ビジュアルデザイン
5. A/Bテスト案の準備

### 動画・モーショングラフィックス
1. コンテ（絵コンテ）作成
2. スクリプト（ナレーション・テロップ）
3. キャラクター/イラスト素材制作
4. アニメーション
5. 音楽・SE・ナレーション
6. レンダリング・納品（各プラットフォーム対応）

## アウトプット品質基準

**優れたビジュアルデザインの条件:**
- 0.5秒で何のブランドかわかる
- 一貫したグリッドとタイポグラフィ
- 競合と明確に差別化されている
- モバイル・デスクトップ両対応
- アクセシビリティ基準（コントラスト比）をクリア

**デザイン提案書の構成:**
```
【ブリーフ確認】目的・ターゲット・KPI
【コンセプト】方向性とキーワード
【ムードボード】参考ビジュアル集
【ビジュアルシステム】カラー・タイポ・アイコン
【適用例】各媒体への展開イメージ
【ガイドライン】使用ルール
```

## クリエイティブの品質基準
- タイポグラフィ：行間 1.5〜1.8倍、文字間隔は読みやすさ優先
- 白スペース：情報の重要度を空白量で表現
- 視線誘導：Zパターン（横型）またはFパターン（縦型）
- フォント：1デザインに最大3種まで
