# ブランドデザイン — ブランディングプレイブック v1.0

## 思考原則
ブランドは「約束」。ロゴではなく、顧客の心の中に存在する感情と期待の総体。一貫した体験の積み重ねがブランド価値を作る。デザインはその約束を視覚で証明する手段。

## 必須フレームワーク

### 1. Brand Identity System
```
Core（核心）
├── Purpose：なぜ存在するか（Why）
├── Vision：目指す世界
├── Mission：果たす使命
└── Values：行動規範（3〜5つ）

Personality（人格）
├── Archetype：ブランドの人格タイプ（12種）
├── Tone of Voice：言葉の使い方
└── Visual Personality：視覚的な個性

Expression（表現）
├── Logo System（複数バリアント）
├── Color System
├── Typography
├── Photography/Illustration
└── Motion
```

### 3. ビジュアルアイデンティティの構成要素
**ロゴシステム**
- プライマリロゴ（カラー・白・黒バリアント）
- セカンダリロゴ（横組み・縦組み）
- アイコン/ファビコン
- 禁止事項（使ってはいけない使い方）

**カラーパレット**
- Primary（ブランドカラー）：1〜2色
- Secondary（補完色）：2〜3色
- Neutral（グレー系）：3〜5段階
- Alert（緑/黄/赤）

**タイポグラフィ**
- Display Font（見出し・インパクト）
- Body Font（本文・読みやすさ）
- 日本語Font（和文対応）
- 使用ルール（サイズ・行間・文字間隔）

### 4. ブランドタッチポイントマッピング
```
認知段階：広告・SNS・PR
検討段階：WEBサイト・資料・動画
購買段階：パッケージ・領収書・購入確認
使用段階：製品・UI・マニュアル
愛着段階：アフターサービス・コミュニティ
推奨段階：ロイヤルティプログラム・UGC
```

## ブランドデザインプロセス

### ブランド戦略策定
1. ビジネス目標の確認
2. ターゲット顧客の定義
3. 競合ブランドポジショニング分析
4. 差別化ポジションの選択
5. ブランドアーキタイプ決定

### ビジュアルアイデンティティ制作
1. ムードボード（方向性の視覚化）
2. ロゴ案3方向提案
3. フィードバック×精緻化
4. フルシステム展開
5. ガイドライン作成

## アウトプット品質基準

**優れたブランドデザインの条件:**
- 3秒で競合と差別化できる
- 10年後も古くならない普遍性
- あらゆるサイズ・媒体で機能する
- ブランドの価値観がビジュアルに宿っている
- チームが迷わず使える明確なガイドライン

**ブランドガイドライン構成:**
```
【ブランドストーリー】Purpose・Vision・Values
【ロゴシステム】使用ルール・禁止事項
【カラーシステム】カラーコード・使用法
【タイポグラフィ】フォント・サイズ規定
【フォトグラフィ】撮影方向・選定基準
【適用例】各媒体でのデザイン例
```
