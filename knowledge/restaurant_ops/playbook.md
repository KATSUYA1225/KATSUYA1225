# 飲食コンサル — F&Bオペレーションプレイブック v1.0

## 思考原則
飲食業の利益は「FLコスト（Food + Labor）を60%以下に抑えること」から始まる。立地と業態と価格帯の整合性が全て。リピーターが売上の7割を作る。

## 必須フレームワーク

### 1. FLコスト管理（最重要）
| コスト | 理想比率 | 危険ライン |
|--------|---------|----------|
| Food（原材料費） | 28-35% | 40%超 |
| Labor（人件費） | 25-30% | 35%超 |
| FL合計 | 55-60% | 65%超 |
| 家賃 | 10%以下 | 15%超 |
| その他経費 | 10-15% | - |
| 営業利益 | 10-15% | 0%以下 |

### 2. メニューエンジニアリング
| | 高人気 | 低人気 |
|--|------|------|
| **高収益** | ⭐ Stars（推奨） | 🧩 Puzzles（告知強化） |
| **低収益** | 🐾 Plowhorses（価格見直し） | 🐕 Dogs（廃止検討） |

**改善行動:**
- Stars：メニュー上段・目立つ場所に配置、価格を微上げ検討
- Puzzles：おすすめ表示・スタッフ推奨で認知向上
- Plowhorses：レシピ見直し・原材料変更でコスト削減
- Dogs：勇気を持って廃止（メニュー数を絞る）

### 3. 回転率管理
売上 = 席数 × 客単価 × 回転数
- 昼：1.5〜2.5回転（ランチ）
- 夜：1.2〜1.8回転（ディナー）
改善：滞在時間の可視化、テーブル設計の見直し

### 4. HACCP（衛生管理）
危害分析重要管理点。食中毒リスクの事前管理。
- 温度管理：食材の適正温度維持記録
- 交差汚染防止：食材・器具の色分け管理
- 従業員衛生：手洗い・健康チェック記録

### 5. 集客・リピート施策
```
新規集客：
└── Google Map最適化（写真・口コミ管理）
└── 食べログ・ぐるなび・Instagram
└── ランチセット・フォトジェニックメニュー

リピート施策：
└── LINE公式アカウント（来店促進クーポン）
└── スタンプカード・メンバーシップ
└── 誕生日・記念日の特別サービス
└── 常連客への個人的な挨拶・記録
```

## 店舗改善プロセス

### 月次経営チェック
1. FL比率・家賃比率の確認
2. 曜日別・時間帯別売上分析
3. メニュー別売上・粗利確認
4. 口コミ・評価のモニタリング
5. 改善優先施策の決定

### 新メニュー開発
1. トレンド調査（SNS・競合）
2. ターゲット顧客の嗜好確認
3. 原価計算（Food Cost率35%以下）
4. テスト提供・スタッフフィードバック
5. 正式メニュー化・オペレーション設計

## アウトプット品質基準

**優れた飲食コンサルのアドバイスの条件:**
- FLコストの具体的な数値目標がある
- メニューエンジニアリングの改善案がある
- 即日実行できる改善施策が含まれる
- 3ヶ月・6ヶ月後の数値目標がある

**店舗改善レポートの構成:**
```
【収益診断】FLコスト・営業利益の現状
【メニュー分析】Stars/Dogs/Puzzles/Plowhorses
【オペレーション課題】ボトルネック特定
【集客・リピート分析】チャネル別効果
【優先改善施策】即効性×重要性マトリクス
【90日ロードマップ】
```
