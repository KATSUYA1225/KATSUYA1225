# 財務分析 — ファイナンスプレイブック v1.0

## 思考原則
財務の目的は「意思決定に必要な数字を提供すること」。P/Lだけでなくキャッシュフロー・バランスシートの3表を統合的に読む。単位経済性（Unit Economics）がビジネスモデルの健全性を示す。

## 必須フレームワーク

### 1. Unit Economics（SaaS/サブスクの基本）
| 指標 | 計算式 | 健全な目安 |
|------|--------|-----------|
| LTV | ARPU × 平均継続月数 | - |
| CAC | 総マーケ・営業費 ÷ 新規顧客数 | LTV/CAC > 3 |
| 回収期間 | CAC ÷ ARPU | < 12ヶ月 |
| チャーン率 | 解約数 ÷ 期首顧客数 | < 2%/月 |
| MRR成長率 | (今月MRR-先月MRR) ÷ 先月MRR | > 10%/月（初期） |

### 2. DCF（ディスカウントキャッシュフロー）分析
事業価値 = Σ(将来FCF ÷ (1 + WACC)^t) + 残存価値
- FCF = EBIT × (1-税率) + 減価償却 - 設備投資 - 運転資本増加
- WACC：加重平均資本コスト（株主資本コスト × 自己資本比率 + 負債コスト × (1-税率) × 負債比率）

### 3. 財務3表の繋がり
```
P/L → 純利益 → BS（利益剰余金）
P/L → 純利益 → CF計算書（営業CF）
BS  → 資産・負債変動 → CF計算書
```

### 4. KPI ダッシュボード
**成長指標**：売上成長率、MRR/ARR、新規顧客数
**効率指標**：GPM（粗利率）、EBITDA率、OPEX比率
**健全性指標**：流動比率、D/Eレシオ、キャッシュランウェイ
**顧客指標**：LTV、CAC、NRR（ネットレベニューリテンション）

### 5. シナリオ分析
| シナリオ | 売上仮定 | コスト仮定 | キャッシュ残高 |
|---------|---------|-----------|-------------|
| ベース | 計画通り | 計画通り | X円 |
| 悲観 | -30% | +10% | Y円 |
| 楽観 | +50% | +5% | Z円 |

## 財務分析プロセス

### 月次財務レビュー
1. P/Lチェック：予算比較、前月比、前年同月比
2. CF確認：営業CF・投資CF・財務CF
3. BS確認：流動比率・自己資本比率
4. KPI更新：顧客単位経済性
5. 問題点洗い出し→経営判断事項のフラグ

### 資金調達検討
1. 現在の月次バーンレート確認
2. キャッシュランウェイ計算（残高÷バーンレート）
3. 調達規模 = 18〜24ヶ月分のオペレーション費用
4. 調達方法比較：エクイティ/デット/補助金
5. 投資家向けFinancial Model作成

### 価格設定分析
- 原価積み上げ：コスト × (1 + 目標マージン率)
- 競合比較：市場平均の上下10%以内
- 価値ベース：顧客が得るROI × 10〜20%
- 推奨：価値ベース × 競合比較のクロスチェック

## アウトプット品質基準

**優れた財務分析レポートの条件:**
- 数字の根拠（データソース）が明示されている
- 前提条件が明確に記載されている
- 3つ以上のシナリオが分析されている
- アクション可能な示唆が含まれている
- グラフ/表で視覚的に理解しやすい

**財務報告書の構成:**
```
【エグゼクティブサマリー】3〜5行の要点
【P/L分析】売上・費用・利益の動向
【CF分析】キャッシュポジション
【KPI状況】目標vs実績
【課題と対策】要注意指標と改善アクション
【予測】翌3ヶ月の見通し
```

## リスク管理
- キャッシュランウェイが6ヶ月を切ったら緊急対応
- 単一顧客への売上集中（>20%）はリスク
- 固定費比率が高い場合、変動費化を検討
- 為替リスク：海外収益があれば為替ヘッジ検討
