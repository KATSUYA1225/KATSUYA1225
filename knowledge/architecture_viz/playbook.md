# 建築プレゼン — アーキテクチャプレイブック v1.0

## 思考原則
建築プレゼンは「設計の技術」を「感動」に変換すること。クライアントは図面を読めなくても、完成後の自分の姿は想像できる。その想像を最高の形で提供する。

## 必須フレームワーク

### 1. プレゼンテーションの5層構造
1. **コンセプト**：この建物が存在する理由・想い
2. **敷地分析**：環境・法規・課題への回答
3. **空間体験**：動線・光・素材の提案
4. **技術的解決**：構造・設備・コスト
5. **完成ビジョン**：人が使っている姿のシミュレーション

### 2. ビジュアライゼーション段階
```
コンセプトスケッチ（手描き/ダイアグラム）
    ↓
BIMモデル（Revit/ArchiCAD）
    ↓
3Dレンダリング（Lumion/V-ray/Enscape）
    ↓
動画ウォークスルー
    ↓
VR体験（オプション）
```

### 3. 素材・マテリアルプレゼンの要素
- サンプルボード：実触感のある素材提示
- 光環境シミュレーション：朝・昼・夕・夜の表情
- 経年変化：5年・10年後の姿

### 4. コスト管理フレームワーク
| 項目 | 標準的な比率 |
|------|------------|
| 建築工事 | 65-70% |
| 設備工事（電気・給排水・空調） | 20-25% |
| 外構工事 | 5-10% |
| 設計監理費 | 工事費の10-15% |
| 諸経費（確認申請等） | 3-5% |

### 5. BIMワークフロー
```
設計者：BIMモデル作成（意匠・構造・設備）
    ↓
施工者：施工BIMへ変換
    ↓
クライアント：3Dビューワーで確認
    ↓
完成後：FMへ引き継ぎ（設備情報管理）
```

## プレゼン制作プロセス

### クライアントヒアリング
1. 機能要件（室数・面積・用途）
2. 感性要件（どんな雰囲気・ライフスタイル）
3. 予算・スケジュール
4. 参考事例（好み・嫌い）
5. 将来的な変化への対応

### 提案書作成
1. コンセプトの言語化（1文で表現）
2. 配置図・平面図・断面図・立面図
3. パース（外観・内観）
4. 空間体験のシーケンス（入口→廊下→リビング）
5. 素材・仕上げの提案
6. 概算工事費

## アウトプット品質基準

**優れた建築プレゼンの条件:**
- コンセプトが1文で明確に語れる
- クライアントの「暮らし・使い方」が具体的に見える
- 光と影・素材感が伝わるビジュアル
- 現実的なコスト計画が示されている
- 「完成後の自分」をイメージできる

**建築提案書の構成:**
```
【コンセプト】設計の核心（1ページ）
【敷地・環境分析】制約と機会
【空間構成】平面・断面・動線計画
【外観・内観パース】完成イメージ
【素材・仕上げ】マテリアルプラン
【工程・費用】スケジュールと概算
```
