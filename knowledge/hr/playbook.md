# 人事・組織 — HRプレイブック v1.0

## 思考原則
「人が最大の資産」は本当だが、「適切な人を適切なポジションに配置すること」が最大のレバレッジ。採用の失敗コストは年収の3倍。文化は採用で決まる。

## 必須フレームワーク

### 1. 採用の漏斗（Hiring Funnel）
```
認知→応募→書類選考→面接→オファー→入社→定着
各段階の転換率を測定し、最大ドロップポイントを改善
```

### 2. 9-Box Talent Grid（人材評価）
| | 低パフォーマンス | 中パフォーマンス | 高パフォーマンス |
|--|---------------|---------------|---------------|
| **高ポテンシャル** | 課題を解明 | 育成対象 | 次世代リーダー |
| **中ポテンシャル** | 改善計画 | コア人材 | 専門家として活用 |
| **低ポテンシャル** | 転職支援 | 現職維持 | 引き止め対象 |

### 3. OKRアライメント
個人OKR → チームOKR → 部門OKR → 全社OKR の整合性確認。
「自分の仕事が会社のどの目標に貢献しているか」を全員が言える状態が理想。

### 4. Employee NPS（eNPS）
「この会社を友人・知人に職場として薦めますか？（0〜10点）」
- Promoter（9-10）：強力な文化伝道者
- Passive（7-8）：現状維持、流出リスクあり
- Detractor（0-6）：組織の足を引っ張る可能性
eNPS = Promoter% - Detractor%（目標：30以上）

### 5. Competency Framework
役割別のコンピテンシーを定義し、評価・採用・育成の基準に。
```
Leadership（全員）：問題解決・コミュニケーション・学習意欲
Individual（個別）：専門スキル・業界知識・ツール習熟度
Culture（全員）：自社の価値観との整合性
```

## 採用プロセス

### 採用要件定義
1. なぜ採用するか（成長/欠員補充/新規能力獲得）
2. Job Description作成（Success Profile中心）
3. 採用基準の点数化（Must/Want/Nice-to-have）
4. 採用チームとプロセス確認

### 面接設計
- 構造化面接：全候補者に同じ質問
- STAR法：Situation/Task/Action/Result
- ワークサンプルテスト：実際の仕事をやってもらう
- カルチャーフィット確認（価値観の整合性）

### オンボーディング（90日計画）
- Day 1：ツール・環境セットアップ・チーム紹介
- Week 1：会社・プロダクト・業務理解
- Month 1：初期成果を出す小タスク
- Month 3：独立した業務遂行

## アウトプット品質基準

**優れた人事制度設計の条件:**
- 従業員の行動変容につながる（理念でなく実務に落ちている）
- 公平性・透明性が担保されている
- シンプルで運用できる
- ビジネス目標と連動している

**HR報告書の構成:**
```
【人員状況】在籍・採用・退職トレンド
【eNPS・エンゲージメント】スコアと主要課題
【採用進捗】各ポジションの選考状況
【育成状況】研修実施・スキル習得状況
【推奨アクション】優先度付き改善施策
```

## 組織文化醸成
- 採用で文化を守る（スキルは教えられるが価値観は難しい）
- 評価・称賛で行動を強化する
- ManagerのManagerが文化の最大の決定要因
- 透明性：情報の非対称性を減らす
