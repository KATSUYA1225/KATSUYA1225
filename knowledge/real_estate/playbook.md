# 不動産マーケ — 不動産プレイブック v1.0

## 思考原則
不動産は「立地・立地・立地」。しかし現代では「データ・デジタル集客・顧客体験」が差別化要因。感情的な購買決定を数字で裏付けし、信頼関係を武器にする。

## 必須フレームワーク

### 1. 投資分析指標
| 指標 | 計算式 | 目安 |
|------|--------|------|
| 表面利回り | 年間家賃収入 ÷ 購入価格 | 5〜8%（都市） |
| 実質利回り | (年収-諸経費) ÷ (購入価格+諸費用) | 3〜5%（都市） |
| CCR | 年間CF ÷ 自己資金 | 10%以上 |
| キャップレート | NOI ÷ 物件価格 | 市場相場比較 |
| LTV | ローン ÷ 物件価値 | 80%以下 |

### 2. 市場分析フレームワーク
```
マクロ分析：
├── 人口動態（増減・流入出）
├── 雇用・経済動向
├── 金利・金融政策
└── 政策・法規制

エリア分析：
├── 徒歩圏の利便施設（駅・スーパー・学校）
├── 周辺開発計画
├── 競合物件の供給状況
└── 賃料・成約価格のトレンド
```

### 3. 顧客別アプローチ
| 顧客タイプ | 主な関心事 | 提案ポイント |
|---------|----------|-----------|
| 実需（居住用） | 生活利便・教育環境・安全性 | ライフスタイル提案 |
| 投資家 | 利回り・キャピタルゲイン | 数字と実績で説得 |
| 法人（テナント） | コスト・立地・スペック | ROI計算・移転メリット |
| 売却希望 | 高値・スピード・手間レス | 査定根拠と実績 |

### 4. デジタル集客戦略
```
オーガニック：
└── SEO（地名+物件種別キーワード）
└── Googleマイビジネス最適化
└── YouTube（物件紹介・エリア動画）

有料：
└── Google/Yahoo!リスティング広告
└── Facebook/Instagram（エリアターゲティング）
└── SUUMOなど不動産ポータルへの出稿
```

### 5. 商談・成約プロセス
1. 初回相談（ヒアリング：予算・条件・優先順位）
2. マッチング物件の選定（3〜5件に絞る）
3. 内見（物件の強みを先に説明してから見せる）
4. 条件確認・交渉（価格・条件の落とし所）
5. 契約・決済（全プロセスの詳細説明）
6. アフターフォロー（紹介・次回購入へ）

## 不動産マーケプロセス

### 物件査定の根拠
- 成約事例比較法（直近6ヶ月の周辺事例）
- 原価法（建物再調達コスト + 土地時価）
- 収益還元法（投資物件の場合）

### ポートフォリオ戦略（投資家向け）
- 分散：エリア分散 / 物件種別分散
- キャッシュフロー物件 × キャピタルゲイン物件のバランス
- 出口戦略（売却時期・相手）を買う前に考える

## アウトプット品質基準

**優れた不動産提案の条件:**
- 顧客の目的（実需/投資/事業用）に合った分析
- 定量的な収益シミュレーション
- リスク（空室・修繕・金利上昇）の明示
- 地域の将来性（人口・開発計画）の評価

**物件提案書の構成:**
```
【顧客要望の確認】条件・予算・優先順位
【マーケット概況】エリアの市況
【物件詳細】スペック・立地・周辺環境
【収益シミュレーション】投資の場合
【リスク分析】注意点と軽減策
【比較案】代替物件との優劣
【推奨・次のステップ】
```
