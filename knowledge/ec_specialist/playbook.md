# EC・通販専門 — Eコマースプレイブック v1.0

## 思考原則
ECは「数字のゲーム」。CVR × 客単価 × リピート率が全て。感覚ではなくデータで改善し、顧客体験の各タッチポイントを最適化する。D2Cブランドの成功は信頼とコミュニティが土台。

## 必須フレームワーク

### 1. ECの3大KPI
| KPI | 計算式 | 改善ポイント |
|-----|--------|-----------|
| CVR | 購入数 ÷ 訪問者数 | LP・カート最適化 |
| 客単価 | 売上 ÷ 購入件数 | アップセル・バンドル |
| LTV | 客単価 × 購買頻度 × 継続期間 | CRM・リピート施策 |

**売上 = 訪問者数 × CVR × 客単価**

### 2. D2C成長フライホイール
```
コンテンツ/SNS → 新規認知
    ↓
LP最適化 → 購買転換
    ↓
梱包・同梱物 → 感動体験
    ↓
CRM・メール → リピート促進
    ↓
レビュー・UGC → 口コミ拡散
    ↓（最初に戻る）
```

### 3. カート離脱対策
平均カート離脱率は70%。対策：
- リターゲティング広告（24h/72h/7d）
- カート放棄メール（1h/24h/72h後）
- 配送料の透明化（隠れコスト排除）
- 1ページチェックアウト
- 決済方法の充実（コンビニ/後払い/アップルペイ）

### 4. 商品ページ最適化（CVR向上）
```
[ ファーストビュー ]
高品質画像（6〜8枚）×動画1本
価格・在庫状況・送料明示
CTAボタン（目立つ色・大きさ）
スマホ最適化（タップしやすいボタン）

[ 購入動機 ]
レビュー・評価（4.0以上・50件以上で効果大）
使用シーン・ライフスタイル画像
Q&A・よくある不安への回答
限定感・緊急性の演出

[ 信頼性 ]
SSL・安全決済バッジ
返品ポリシーの明示
企業情報・問い合わせ先
SNSフォロワー数・メディア掲載
```

### 5. メール・LINEマーケティング（CRM）
| シナリオ | タイミング | 開封率目標 |
|---------|-----------|-----------|
| ウェルカム | 登録直後 | 50%+ |
| 購入後フォロー | 3日後 | 35%+ |
| リピート促進 | 30日後 | 25%+ |
| カート放棄 | 1時間後 | 40%+ |
| 誕生日 | 当日 | 45%+ |
| Win-back | 90日未購入 | 20%+ |

## EC運営プロセス

### 月次PDCAサイクル
1. KPI確認（売上・CVR・客単価・LTV）
2. 広告ROAS分析（目標：3以上）
3. SKU別売上・在庫確認
4. カスタマーレビュー分析
5. 改善施策の優先順位決定

### 商品企画
1. ターゲット顧客の明確化
2. 競合リサーチ（価格・差別化・レビュー）
3. コンセプト・USP設定
4. 価格設計（原価 × 粗利率 × 市場価格）
5. テスト販売 → 反応確認 → 量産判断

## アウトプット品質基準

**優れたEC戦略レポートの条件:**
- 現状KPIのボトルネック特定
- 施策のROI（投資回収）試算
- 競合差別化の明確化
- 90日アクションプラン

**EC改善提案の構成:**
```
【現状診断】KPI・ファネル分析
【問題定義】最大のボトルネック
【施策提案】優先度×ROI期待値
【実行計画】誰が・何を・いつまでに
【KPI目標】改善後の数値目標
```
