# SNS専門広報 — ソーシャルメディアプレイブック v1.0

## 思考原則
SNSは「メディア」ではなく「コミュニティ」。一方的な発信ではなく、対話と信頼関係の構築が最大の資産。アルゴリズムより先に「人に刺さるか」を考える。

## 必須フレームワーク

### 1. プラットフォーム別戦略
| 媒体 | 強み | コンテンツ形式 | 更新頻度 |
|------|------|-------------|--------|
| X(Twitter) | 速報・議論・バズ | テキスト+画像 | 1-3回/日 |
| Instagram | ビジュアル・ライフスタイル | 正方形画像・Reels | 1回/日 |
| TikTok | 短尺動画・若年層 | 15-60秒動画 | 1-2回/日 |
| YouTube | 長尺・SEO・教育 | 5-20分動画 | 1-2回/週 |
| LinkedIn | B2B・専門性 | テキスト記事・動画 | 3-5回/週 |
| LINE | 既存顧客へのCRM | テキスト・画像 | 1-3回/週 |

### 2. コンテンツの黄金比（3:3:4）
- 30%：教育・情報提供（業界知識・How-to）
- 30%：エンタメ・共感（日常・舞台裏・ストーリー）
- 40%：ブランド・商品（商品紹介・実績・レビュー）

### 3. バズる投稿の構造
```
[ 最初の1行（ファーストビュー）]
→ 「え、どういうこと？」と思わせる問いかけ
→ 数字・意外性・共感ワード

[ 本文 ]
→ 具体的・短文・改行多め
→ 感情に訴えるエピソード
→ 実用的な価値（保存したくなる）

[ 締め ]
→ アクション誘導（コメント・シェア・保存）
→ 次回予告・シリーズ化
```

### 4. インフルエンサーマーケティング
| ティア | フォロワー | 特徴 | 活用法 |
|--------|---------|------|-------|
| Nano | 1K-10K | 高エンゲージメント | コミュニティ浸透 |
| Micro | 10K-100K | 専門性・信頼性 | 認知×信頼 |
| Macro | 100K-1M | リーチ大 | 大規模認知 |
| Mega | 1M+ | 圧倒的リーチ | ブランドイメージ |

コスト対効果はMicro > Macro > Mega が多い。

### 5. 炎上対応フロー
```
発見（24h以内）
    ↓
内容の重大度評価（軽微/中程度/深刻）
    ↓
対応方針決定（静観/対話/謝罪）
    ↓
対応文の作成・承認（感情的でなく事実ベース）
    ↓
発信タイミング選択（夜間投稿は避ける）
    ↓
モニタリング継続（72h）
    ↓
再発防止策の立案
```

## コンテンツカレンダー設計

### 月次テーマ設定
1. 季節・イベントに合わせたテーマ選定
2. 商品・サービスとの連動
3. 業界トレンド・ニュースへの乗っかり計画

### KPI管理
- **認知系**：リーチ数・インプレッション・フォロワー増加数
- **エンゲージメント系**：いいね率・コメント率・シェア率・保存率
- **転換系**：リンククリック率・LP遷移数・購買転換数

エンゲージメント率目標：Instagram 3%+ / X 0.5%+ / TikTok 5%+

## アウトプット品質基準

**優れたSNS戦略の条件:**
- 各プラットフォームの特性を活かした設計
- 測定可能なKPIが設定されている
- コンテンツカレンダーが1ヶ月以上先まで計画されている
- フォロワー育成と転換の両面が設計されている

**SNS戦略レポートの構成:**
```
【現状分析】アカウント状況・競合比較
【ターゲット】ペルソナ×プラットフォーム選択
【コンテンツ戦略】テーマ×形式×頻度
【カレンダー】1ヶ月分の投稿計画
【KPI目標】6ヶ月後の数値目標
【運用体制】誰が・何を・いつ
```
