# 医療・介護 — ヘルスケアプレイブック v1.0

## 思考原則
医療・介護の価値は「患者・利用者の生活の質（QOL）向上」。コンプライアンスと安全性が最優先。同時に経営の持続可能性（黒字運営）なしに医療は続けられない。

## 必須フレームワーク

### 1. 医療経営の4指標
| 指標 | 内容 | 目標 |
|------|------|------|
| 病床稼働率 | 入院患者数÷許可病床数 | 80%以上 |
| 外来患者数/日 | 平均外来患者数 | 前年比維持〜増加 |
| 医業収益 | 診療報酬+自費収入 | 原価率70%以下 |
| 人件費率 | 人件費÷医業収益 | 50%以下 |

### 2. 患者体験（Patient Experience）
```
来院前：
└── WEB予約・インターネット検索
└── 口コミ・評判（Googleレビュー）

来院時：
└── 待ち時間（目標30分以内）
└── 受付・スタッフの対応
└── 施設の清潔感・利便性

診療中：
└── 医師の説明の丁寧さ（IC：インフォームドコンセント）
└── 痛み・不安への配慮

来院後：
└── フォローアップ・リマインダー
└── 継続受診の動機付け
```

### 3. 医療安全（Patient Safety）
- ヒヤリハット収集：月30件以上で安全文化あり
- RCA（根本原因分析）：インシデント後の再発防止
- SBAR（報告様式）：Situation/Background/Assessment/Recommendation

### 4. 介護事業の収益構造
```
収益：介護報酬（公定価格）+ 自費サービス
費用：人件費（65%）+ 物件費（10%）+ その他（15%）
利益：10%以上を目指す
加算取得：各種加算（処遇改善・LIFE活用）で単価向上
```

### 5. デジタルヘルス活用
- 電子カルテ：入力効率化・情報共有
- 予約システム：無断キャンセル削減・待ち時間改善
- 遠隔診療：アクセシビリティ向上・地方医療
- PHR（個人健康記録）：継続的な健康管理

## 医療・介護経営プロセス

### 患者獲得・維持
1. Google検索対策（地域名+診療科）
2. Googleビジネスプロフィール管理
3. 患者満足度調査の定期実施
4. 予防医療・定期検診の啓発

### スタッフ管理
- 医療職の離職率：平均10-15%、目標10%以下
- 面接・採用時の価値観確認
- 教育・研修の充実（特に医療安全）
- 働き方改革（勤務体制・時間外削減）

## アウトプット品質基準

**優れた医療・介護コンサルアドバイスの条件:**
- 法令・診療報酬改定への対応が含まれる
- 患者安全と経営効率のバランスが取れている
- スタッフが実行できる具体的な手順
- コンプライアンスリスクの指摘がある

**医療経営改善レポートの構成:**
```
【経営状況】主要指標の現状と課題
【患者体験分析】CS・NPS・口コミ分析
【医療安全状況】インシデント・リスク評価
【収益改善案】加算取得・自費展開
【人材・組織】採用・教育・定着施策
【デジタル化提案】DX投資対効果
```
