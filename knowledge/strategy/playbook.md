# 経営戦略 — 戦略立案プレイブック v1.0

## 思考原則
戦略とは「何をしないかを決めること」。リソースは有限であり、選択と集中が競争優位の源泉。良い戦略は「診断→基本方針→実行施策」の3層構造を持つ。

## 必須フレームワーク

### 1. Blue Ocean Strategy
競争のない新市場を創造する戦略。
- **ERRC グリッド**：何を Eliminate/Reduce/Raise/Create するか
- バリューカーブで競合との差異を可視化
- 非顧客を顧客に変える施策立案

### 2. Porter's Generic Strategies
| 戦略 | 内容 | 適用条件 |
|------|------|---------|
| コストリーダーシップ | 最低コスト | 大市場・規模の経済 |
| 差別化 | 独自価値 | 価値志向顧客・ブランド力 |
| 集中（コスト） | ニッチ低コスト | 特定セグメント |
| 集中（差別化） | ニッチ高価値 | 特定顧客の深い理解 |

### 3. Ansoff Matrix（成長戦略）
| | 既存製品 | 新規製品 |
|--|---------|---------|
| **既存市場** | 市場浸透（最も安全） | 製品開発 |
| **新規市場** | 市場開発 | 多角化（最もリスク） |

### 4. BCG成長率-市場シェアマトリクス
- 🌟 スター：高成長・高シェア → 投資維持
- 💰 金のなる木：低成長・高シェア → 収益化
- ❓ 問題児：高成長・低シェア → 投資か撤退か判断
- 🐕 負け犬：低成長・低シェア → 撤退検討

### 5. VRIO分析
| 要素 | 問い | 判定 |
|------|------|------|
| Value | 顧客価値を創出しているか | Y/N |
| Rarity | 競合が持っていないか | Y/N |
| Imitability | 模倣困難か | Y/N |
| Organization | 組織が活用できているか | Y/N |
→ 全てYなら持続的競争優位

### 6. シナリオプランニング
不確実性の高い変数2つを軸に4つのシナリオを描く。
各シナリオでの対応策を事前に準備することでレジリエンス向上。

## 戦略立案プロセス

### 現状分析フェーズ
1. PEST分析：マクロ環境（政治/経済/社会/技術）
2. Porter's Five Forces：業界構造
3. SWOT分析：内部（強み/弱み）× 外部（機会/脅威）
4. VRIO：持続的競争優位の源泉特定

### 戦略策定フェーズ
1. ビジョン・ミッション確認
2. 3〜5年の定量目標設定
3. 競争優位の選択（何で勝つか）
4. 戦略オプション列挙（3案以上）
5. 評価基準で最優先戦略選択

### 実行計画フェーズ
1. 戦略をOKRに分解
2. 部門別ロードマップ作成
3. KPIダッシュボード設計
4. 四半期レビュー体制構築

## アウトプット品質基準

**優れた戦略文書の条件:**
- 現状分析が客観的データに基づいている
- 「何をしないか」が明確に定義されている
- 3年後のありたい姿が具体的に描かれている
- 実行の優先順位と責任者が決まっている
- リスクシナリオと対応策が含まれている

**戦略レポートの構成:**
```
【エグゼクティブサマリー】結論と要点（1ページ）
【現状分析】SWOT + 競合ランドスケープ
【戦略方針】選択した競争戦略とその根拠
【3ヵ年ロードマップ】フェーズ別目標
【重点施策】TOP 5施策と期待成果
【リスク管理】主要リスクと軽減策
【KPI一覧】測定指標と目標値
```

## よくある戦略の失敗
- 「全部やる」戦略：集中投下できず全て中途半端
- 競合コピー：独自性がなく価格競争に陥る
- 実行なき完璧な計画：80点の戦略でも実行力で勝る
- 環境変化への適応遅れ：年1回しか戦略を見直さない
