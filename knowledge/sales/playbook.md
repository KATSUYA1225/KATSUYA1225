# 営業専門 — セールスプレイブック v1.0

## 思考原則
売れる営業は「売り込まない」。顧客の課題を深く理解し、解決策を提示することで自然と成約する。信頼構築→課題発見→解決提案→合意の4ステップ。

## 必須フレームワーク

### 1. SPIN Selling（質問技術）
| 質問種別 | 目的 | 例 |
|---------|------|----|
| Situation | 現状把握 | 「現在どのような方法で〇〇を行っていますか？」 |
| Problem | 問題特定 | 「その方法での課題は何ですか？」 |
| Implication | 問題の深刻化 | 「それが解決されないと業務にどう影響しますか？」 |
| Need-payoff | 解決価値 | 「もし解決できたらどのくらいの改善が見込めますか？」 |

### 2. MEDDIC（商談管理）
- **M**etrics：顧客の成功指標は何か
- **E**conomic Buyer：最終決裁者は誰か
- **D**ecision Criteria：どんな基準で選ぶか
- **D**ecision Process：どのような承認フローか
- **I**dentify Pain：本当の痛みは何か
- **C**hampion：内部で推進してくれる人は誰か

### 3. Challenger Sale（主体的な価値提供）
顧客が気づいていない課題を「教えて」、新たな視点を「提供し」、自社ソリューションへ「誘導する」。
1. Warm up：業界トレンドで信頼構築
2. Reframe：盲点を指摘して問題再定義
3. Rational Drowning：データで課題の深刻さを証明
4. Emotional Impact：個人的な危機感を喚起
5. Value Proposition：自社の解決策を提示

### 4. パイプライン管理
| ステージ | 確度 | アクション |
|---------|------|----------|
| 初回接触 | 10% | ニーズヒアリング |
| 課題確認 | 30% | 提案資料作成 |
| 提案済み | 50% | 決裁者接触 |
| 交渉中 | 70% | 条件調整 |
| 契約直前 | 90% | 書類準備 |

## 営業プロセス

### 新規開拓
1. ICP（理想顧客プロファイル）定義
2. ターゲットリスト作成（100社以上）
3. コールドアプローチ（メール/電話/LinkedIn）
4. ニーズ確認MTG設定（15分ファーストコール）
5. 課題ヒアリング（30〜60分）
6. 提案書作成・プレゼン
7. クロージング

### クロージング技術
- **仮定クロージング**：「ご契約いただけた場合、いつから始めたいですか？」
- **代替クロージング**：「AプランとBプランどちらがよりご要望に合いますか？」
- **緊急性クロージング**：「今月末までにご決断いただくと特典Xをご用意できます」

### 価格交渉
- 値引き要求には即答しない（承認が必要と伝える）
- 値引きする場合は必ず何かを引き換えに要求する
- ROI計算を提示して「投資対効果」で価格を正当化

## アウトプット品質基準

**優れた提案書の条件:**
- 顧客の言葉（ヒアリング内容）が反映されている
- 現状の課題→解決後のビジョンが明確
- 定量的なROI（コスト削減額・売上増加見込み）が示されている
- 競合との差別化ポイントが3つ以上
- 実装スケジュールと次のアクションが明確

**提案書の構成:**
```
【現状把握】ヒアリングで確認した課題（顧客の言葉で）
【課題の影響】このまま放置するとどうなるか
【解決策】提案内容と選定理由
【実績・証拠】類似事例・数値
【ROI試算】投資対効果の定量計算
【プラン】価格・期間・サポート内容
【次のステップ】具体的なアクションと期限
```

## 失注分析の必須項目
- 競合に負けた理由（価格/機能/信頼/関係性）
- 自社で改善できる点
- タイミングの問題か本質的な問題か
- 将来の再アプローチ計画

## 避けるべき失敗パターン
- 機能説明に終始して価値を伝えない
- 決裁者と会わずに担当者レベルで止まる
- 値引きを先に提示して価値を下げる
- フォローアップの頻度が低すぎる（週1連絡が基本）
