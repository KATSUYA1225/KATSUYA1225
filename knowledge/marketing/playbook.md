# マーケティング — 戦略プレイブック v1.0

## 思考原則
マーケティングの本質は「正しい人に・正しいメッセージを・正しいタイミングで届けること」。インバウンドで顧客を引き寄せ、データで意思決定する。

## 必須フレームワーク

### 1. Jobs-to-be-Done (JTBD)
顧客は「製品」ではなく「仕事（Job）」を雇う。
- Functional Job：タスクを完遂したい
- Emotional Job：どう感じたいか
- Social Job：他者からどう見られたいか
- 例：ドリルではなく「穴」が欲しい → 実は「棚を設置した達成感」が欲しい

### 2. AARRR（パイレーツメトリクス）
| Stage | 指標 | 目標設定例 |
|-------|------|-----------|
| Acquisition | CAC, チャネル別流入 | CAC < LTV/3 |
| Activation | 初回価値到達率 | 初回7日以内のキーアクション |
| Retention | 30/60/90日継続率 | D30 > 20% |
| Revenue | ARPU, LTV | LTV > CAC × 3 |
| Referral | NPS, 紹介率 | NPS > 50 |

### 3. コンテンツマーケティング フライホイール
認知 → 興味 → 検討 → 購買 → 推奨 の各ステージに合ったコンテンツ設計。
- トップファネル：SEO記事・SNS・動画（量）
- ミドル：ウェビナー・ホワイトペーパー・比較コンテンツ
- ボトム：事例・デモ・無料トライアル

### 4. STP分析
- **Segmentation**：地理/人口統計/心理/行動の4軸で市場分割
- **Targeting**：TAM→SAM→SOMで現実的な市場規模を算定
- **Positioning**：競合マップ上の独自ポジション特定

### 5. 4C分析（顧客視点の4P）
| 従来4P | 顧客視点4C |
|--------|-----------|
| Product | Customer Value |
| Price | Cost（顧客の総コスト） |
| Place | Convenience |
| Promotion | Communication |

## 戦略立案プロセス

### ブランド戦略
1. ブランドパーソナリティ定義（5形容詞）
2. ブランドプロミス（顧客への約束を1文で）
3. トーン&マナー設定（言葉・ビジュアル基準）
4. カスタマージャーニーマップ作成

### デジタルマーケティング戦略
1. KPI設定：MQL→SQL→成約の転換率目標
2. チャネル選定：ターゲット層の行動データ基準
3. コンテンツカレンダー：月次テーマ×媒体マトリクス
4. A/Bテスト計画：仮説→検証→学習の高速サイクル

### 予算配分（目安）
- 認知獲得：40%（SEO/SNS/PR）
- リード獲得：35%（広告/LP最適化）
- 育成・維持：25%（メール/コンテンツ）

## アウトプット品質基準

**優れたマーケティング戦略書の条件:**
- ターゲットペルソナが具体的（年齢・職業・悩み・情報収集行動まで）
- 差別化ポイントが競合比較で明確
- KPIと測定方法が定義済み
- 予算ROI試算が含まれる
- 90日アクションプランが付いている

**マーケティング施策提案の構成:**
```
【現状診断】現在のファネル状況と課題
【ターゲット】ペルソナ定義（JTBD含む）
【戦略方針】STP + ポジショニング
【施策詳細】チャネル×コンテンツ×予算
【KPI】主要指標と目標値
【スケジュール】90日ロードマップ
```

## 業界別重点施策
- BtoB：コンテンツ×ABM（アカウントベースドマーケティング）
- BtoC：SNS×UGC（ユーザー生成コンテンツ）×インフルエンサー
- SaaS：PLG（プロダクトレッドグロース）×トライアル最適化
- 小売：オムニチャネル×ロイヤルティプログラム

## 注意すべきマーケティングの落とし穴
- バニティメトリクス（いいね数・PV）に惑わされない
- ブランドと直接反応広告のバランスを崩さない（6:4が目安）
- チャネル分散しすぎて全てが中途半端になる
- 短期ROIのみ追求してブランド毀損する
