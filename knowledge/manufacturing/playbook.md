# 製造業・職人 — ものづくりプレイブック v1.0

## 思考原則
製造の競争力は「品質 × コスト × 納期」の3軸。日本の強みは「カイゼン文化」と「職人技術」。デジタル化でその強みを最大化する。作りすぎ・在庫過多が最大の無駄。

## 必須フレームワーク

### 1. トヨタ生産方式（TPS）の7つの無駄
1. 作りすぎ（最大の無駄）
2. 手待ち
3. 運搬
4. 加工の無駄
5. 在庫
6. 動作の無駄
7. 不良・手直し

→ これらをVSM（バリューストリームマッピング）で可視化して排除

### 2. PDCA × カイゼン
```
Plan（計画）：改善目標と手順の明確化
Do（実行）：小さく始める
Check（確認）：数値で効果測定
Act（改善）：標準化または再計画
→ 全員参加・毎日改善が文化になるまで続ける
```

### 3. 品質管理（QC）7つ道具
1. 特性要因図（魚の骨）：原因分析
2. パレート図：重要問題の絞り込み（80/20）
3. ヒストグラム：ばらつきの可視化
4. 管理図：工程の安定性監視
5. 散布図：相関関係の把握
6. チェックシート：データ収集
7. グラフ・層別：傾向把握

### 4. OEE（設備総合効率）
OEE = 時間稼働率 × 性能稼働率 × 良品率
- 世界水準：85%以上
- 日本平均：60-65%
- 改善余地の大きいボトルネックを特定して集中

### 5. SCM（サプライチェーン管理）
```
調達 → 製造 → 在庫 → 出荷 → 顧客
各段階のリードタイム × 在庫水準を最適化
JIT（ジャストインタイム）：必要な時に必要な量だけ
```

## 製造改善プロセス

### 現場分析
1. ゲンバ（現場）歩き：実際に観察
2. VSM作成：材料から出荷までの流れ可視化
3. ボトルネック特定
4. 改善優先順位決定（効果×実行容易性）

### 職人技術のデジタル化
1. 技術・ノウハウの言語化（動画・文書）
2. 作業標準書の作成
3. IoTセンサーでの工程データ収集
4. AIによる異常検知・品質予測

### 原価管理
- 材料費・労務費・製造間接費の分解
- 活動基準原価計算（ABC）でコスト構造把握
- ロス率の日次管理

## アウトプット品質基準

**優れた製造コンサルアドバイスの条件:**
- 数値目標（OEE・不良率・リードタイム）が明確
- 実行可能なカイゼン施策リスト
- 投資対効果（コスト削減額）の試算
- 従業員が実行できるシンプルな手順

**製造改善レポートの構成:**
```
【現状診断】OEE・品質・コスト・納期の現状
【問題の優先順位】パレート分析
【改善提案】カイゼン施策×期待効果
【実行計画】担当者×期限×目標値
【投資対効果】ROI計算
```
