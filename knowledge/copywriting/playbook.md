# コピーライター — コピープレイブック v1.0

## 思考原則
言葉は最も強力なマーケティングツール。良いコピーは「読まれる・信じられる・行動される」の3条件を満たす。顧客の頭の中にある言葉を使うことが最大の技術。

## 必須フレームワーク

### 1. AIDA（古典的コピー構造）
- **A**ttention：注意を引く（ヘッドライン）
- **I**nterest：興味を持たせる（サブ情報）
- **D**esire：欲しいと思わせる（ベネフィット）
- **A**ction：行動させる（CTA）

### 2. PAS（問題解決型）
- **P**roblem：問題を明示（読者の痛みを言語化）
- **A**gitate：問題を深掘り（放置するとどうなるか）
- **S**olve：解決策の提示（自然な流れでオファー）

### 3. Before/After/Bridge
- **Before**：現在の状況（問題・制約・不満）
- **After**：理想の状態（解決後のビジョン）
- **Bridge**：どうやってAfterへ行くか（プロダクト）

### 4. ヘッドラインの11パターン
1. 数字：「3ヶ月で売上2倍になった5つの方法」
2. 疑問：「なぜあなたの広告はクリックされないのか？」
3. ハウツー：「初心者でも今日から使えるSEO入門」
4. 逆張り：「マーケティング予算ゼロで月100件の問い合わせ」
5. 社会的証明：「3,000社が選んだ理由」
6. 緊急性：「今月末で終了：〇〇キャンペーン」
7. 恐怖：「このまま放置すると取り返しのつかないことに」
8. 特定化：「30代女性経営者が6ヶ月で達成した3つのこと」
9. 秘密：「業界のプロが教えてくれない本当のこと」
10. 挑戦：「30日で結果が出なければ全額返金」
11. 限定：「今だけ・ここだけ・あなただけ」

### 5. 証拠（Social Proof）の種類
- 数字の証拠：「導入企業3,000社突破」
- 権威の証拠：「〇〇大学の研究によると」
- ユーザーの声：実名・顔写真付きレビュー
- 受賞・認定：業界賞・取得資格
- メディア掲載：「〇〇紙に掲載されました」

## コピーライティングプロセス

### LP（ランディングページ）コピー
1. ターゲットペルソナの言葉調査（SNS/レビュー）
2. ベネフィット（機能ではなく価値）整理
3. 反論先取り（よくある疑問・不安をリスト化）
4. ヘッドライン複数案作成（10案以上）
5. ボディコピー作成（AIDA/PAS）
6. CTA最適化（動詞から始める）

### SEOコピーライティング
- ターゲットキーワードはタイトル・H1・冒頭100文字に
- 検索意図（Informational/Navigational/Transactional）に合わせた構成
- 読みやすさ：1段落3-4行・小見出し200字ごと
- E-E-A-T：経験・専門性・権威性・信頼性

## アウトプット品質基準

**優れたコピーの条件:**
- ターゲットが「自分のことだ」と感じる
- ベネフィット（機能でなく価値）を伝えている
- 1つのメッセージに絞られている
- 具体的な数字・固有名詞が使われている
- 次のアクションが明確

**コピー提案の構成:**
```
【ターゲット】誰に向けたコピーか
【ゴール】何をしてほしいか（KPI）
【キーメッセージ】一言で伝えるとしたら
【ヘッドライン案】3〜5パターン
【ボディコピー】本文
【CTA】行動喚起テキスト
【A/Bテスト案】検証すべき訴求軸
```

## 避けるべきコピーの失敗
- 機能を列挙してベネフィットを伝えない
- 全員に向けて誰にも刺さらない
- 曖昧な言葉（「高品質」「信頼性の高い」）
- CTAが弱い（「詳しくはこちら」→「今すぐ無料で試す」）
- 長すぎる・読めない文章
