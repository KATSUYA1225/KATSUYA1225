# 強み発見 — ストレングスプレイブック v1.0

## 思考原則
人の可能性は「弱みを直す」ことより「強みを伸ばす」ことで最大化する。強みは「自然にうまくいくこと」。それを言語化し、ビジネスに接続することが最大の価値。

## 必須フレームワーク

### 1. 強みの3層構造
```
才能（Talent）：自然にできること（先天的傾向）
    ×
知識（Knowledge）：学んで身につけた理解
    ×
スキル（Skill）：練習で身についた技術
    ＝
強み（Strength）：一貫して高い結果を出す能力
```

### 2. 強みの発見方法
**内省の質問：**
- 「やっていて時間を忘れる活動は何か？」（フロー体験）
- 「他者より速く上達したことは何か？」
- 「やる前から正解がわかることは何か？」
- 「人に感謝される場面はどんな時か？」
- 「子供の頃に熱中したことは何か？」

**フィードバック分析：**
- 直近1年で褒められたこと10個を書き出す
- 他者が自分に頼ってくること3つを特定する
- 自分が「当たり前」と思っていることで他者が「すごい」と言うことは何か

### 3. StrengthsFinder 34の強み（カテゴリ）
**実行力**：達成欲・アレンジ・信念・公平性・慎重さ・規律性・集中力・責任感・回復志向
**影響力**：活発性・指揮・コミュニケーション・競争性・自己確信・最上志向・社交性・戦略性・着想
**人間関係構築**：適応性・運命思考・共感性・調和性・包含・個別化・ポジティブ・親密性
**思考力**：分析思考・原点思考・未来志向・収集心・内省・学習欲・戦略性

### 4. 強みのビジネス接続
```
強みの特定
    ↓
どんな状況で発揮されるかのパターン認識
    ↓
自社/担当業務での活用機会の発見
    ↓
強みが活かせる役割・タスクへの最適配置
    ↓
チームの強み相補マップの作成
```

### 5. 個人・チームの強みマトリクス
| メンバー | 強み①  | 強み② | 弱点（補完が必要） |
|---------|--------|-------|----------------|
| A | 分析・戦略 | データ | コミュニケーション |
| B | 営業・共感 | 顧客理解 | 計画・構造化 |
→ AとBは相補的なペア：AがプランをBが実行

## 強み発見プロセス

### 個人の強み診断
1. 初回ヒアリング（過去の成功体験の深掘り）
2. 行動パターンの分析
3. 強みの仮説立案（5〜7個）
4. 検証（具体的な場面での確認）
5. 強みプロファイルの作成

### 組織への応用
1. 採用：強みプロファイルに基づくJD作成
2. 配置：強みが発揮できるポジションへの最適化
3. 育成：弱みの補強より強みの発揮環境整備
4. 評価：強みの貢献を定性・定量で評価

## アウトプット品質基準

**優れた強み発見のアウトプットの条件:**
- 本人が「確かにそうだ」と感じる言語化
- 具体的なエピソードと紐付けられている
- ビジネス/業務への応用が明確
- チームや組織への貢献の仕方が見えている

**強み発見レポートの構成:**
```
【あなたのトップ強み】TOP5の詳細説明
【過去の成功パターン】強みが発揮された瞬間
【盲点と可能性】気づいていなかった強み
【ビジネス活用】仕事への具体的な活かし方
【チームへの貢献】組織でどう輝くか
【成長ロードマップ】強みをさらに伸ばすために
```
