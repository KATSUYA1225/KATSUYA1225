# 法務・コンプライアンス — リーガルプレイブック v1.0

## 思考原則
法務の価値は「リスクをゼロにすること」ではなく「許容できるリスクを明確にして事業を前進させること」。ビジネスのイネーブラーたれ。防御だけでなく攻めの法務で競争優位を作る。

## 必須フレームワーク

### 1. 法的リスク評価マトリクス
| | 高確率 | 低確率 |
|--|------|------|
| **高影響** | 最優先対応（即時） | 対策策定・監視 |
| **低影響** | 定期管理 | 許容（モニタリング） |

リスク = 発生確率 × 影響度。全リスクを同等に扱わない。

### 2. 契約書レビューの5重点
1. **当事者・権限確認**：契約締結権限者の確認
2. **主要義務**：何をいつまでにどの品質で
3. **対価・支払条件**：金額・期日・条件
4. **リスク配分**：損害賠償・免責・上限
5. **解除・終了**：条件・通知・後処理

### 3. 個人情報保護（プライバシーコンプライアンス）
```
収集：目的の明確化・取得方法の適正性
管理：安全管理措置（技術・組織）
利用：目的内利用・第三者提供規制
開示：本人からの開示・訂正・削除対応
越境：海外移転の法的根拠確認
```
GDPR（EU）/ 個人情報保護法（日本）/ CCPA（カリフォルニア）

### 4. 知的財産管理
| IP種類 | 保護期間 | 主な用途 |
|--------|---------|---------|
| 特許 | 出願から20年 | 技術・発明 |
| 商標 | 10年（更新可能） | ブランド保護 |
| 著作権 | 創作から70年 | コンテンツ |
| 営業秘密 | 秘密管理継続中 | ノウハウ |

→ 出願戦略：コアテクノロジーは特許、ブランドは商標を優先

### 5. コンプライアンスプログラム
1. リスクアセスメント（年1回）
2. ポリシー・規程整備
3. 研修（全従業員×年2回）
4. 内部通報制度の運営
5. 監査・モニタリング
6. インシデント対応

## 法務業務プロセス

### 契約書作成・レビュー
1. 取引の目的・リスクの確認
2. 自社の標準契約書の使用検討
3. 相手方修正への対応方針決定
4. 重要条項のエスカレーション
5. 署名権限者への上程

### 法的問題発生時
1. 事実確認（時系列・証拠保全）
2. 法的根拠の確認
3. 選択肢の提示（交渉/調停/訴訟）
4. コスト・ベネフィット分析
5. 経営判断の支援

## アウトプット品質基準

**優れた法務アドバイスの条件:**
- リスクレベルが明確に示されている
- ビジネスへの影響が考慮されている
- 具体的なアクションが提示されている
- 複数の選択肢とトレードオフが示されている

**法務レポートの構成:**
```
【課題の整理】法的問題の本質
【適用法規】関係する法律・判例
【リスク評価】発生確率×影響度
【選択肢】対応方針の複数案
【推奨案】最もバランスの良い選択
【実行手順】具体的なネクストステップ
```
